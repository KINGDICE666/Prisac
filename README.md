# Prisac

Минимальная база для 2D roguelike в духе The Binding of Isaac на C# и MonoGame.

## Почему MonoGame

MonoGame - это C#-фреймворк для игр, наследник XNA. Он легче Unity/Godot, но удобнее C++ для старта: код проще читать, а готовую игру можно опубликовать как Windows `.exe`.

Для разработки нужен .NET 8 SDK. Игроку SDK ставить не нужно, если публиковать self-contained сборку.

## Что уже есть

- первая комната с полом, стенами, дверями и камнями;
- игрок с перемещением;
- стрельба в четыре стороны;
- простые враги, которые идут к игроку;
- здоровье, урон, перезапуск комнаты;
- открытие дверей после зачистки.

## Управление

- `WASD` - движение;
- `стрелки` - стрельба;
- `R` - перезапуск комнаты;
- `Esc` или крестик окна - выход.

## Сборка

Установи .NET 8 SDK, затем запусти:

```powershell
powershell -ExecutionPolicy Bypass -File .\build_windows.ps1
```

Скрипт скачает MonoGame-пакет через NuGet и создаст:

```powershell
publish\Prisac.exe
```

Именно этот `.exe` можно отправить другому человеку.
